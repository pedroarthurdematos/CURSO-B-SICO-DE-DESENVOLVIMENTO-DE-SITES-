# 🌐 Curso Básico de Desenvolvimento de Sites

Este repositório contém os exercícios, projetos e anotações do **Curso Básico de Desenvolvimento de Sites** (Carga horária: 68h).

## 📚 Conteúdo do Curso

- **Figma (Prototipagem & UI/UX):** Wireframes, componentes, auto layout e protótipos interativos.
- **HTML5:** Tags semânticas, formulários, tabelas e estruturação web.
- **CSS3:** Estilização visual, modelo de caixa (Box Model), posicionamento e tipografia.

## 🛠️ Ferramentas Utilizadas
- [Figma](https://figma.com)
- [VS Code](https://code.visualstudio.com/)
- HTML5 & CSS3
